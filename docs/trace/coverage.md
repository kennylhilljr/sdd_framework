# Evidence for acceptance criteria

Derived status: which criteria have tests and code entry points citing them with `@spec`, and, when a test report is given, whether those tests pass. Regenerated by `node tools/trace-check/trace-check.mjs --write`; never edit by hand. Deferred and excepted criteria are listed in the test plan's front matter.

Evidence states: `test linked` (a test cites the criterion), `passing` or `failing` (a linked test ran), `planned` (mapped to tests in the test plan or LLD, not written yet), `deferred`, `excepted`, `drifted` (recorded by the verifier) and `gap`. A link is structural: it does not prove that the test checks what the criterion means.
