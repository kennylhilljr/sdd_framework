# Documentation map

This is the map of every document in `docs/`, the layer it belongs to, and its latest version. Agents read it instead of searching for files. The table between the markers is generated by `node tools/sdd/cli.mjs docmap`; the rest is written by people.

## Layers

| Layer | Folder | Owner | Approved at |
| --- | --- | --- | --- |
| L0 Vision and strategy | `vision/` | H | |
| Research | `research/` | A (`analyst`) | |
| L1 Parent PRD | `prd/` | H | Gate 1 |
| L2 Component PRDs | `prd/components/` | H and C | Gate 1 |
| Decisions (ADRs) | `adr/` | C (`architect`) | Gate 2 |
| L3 SPEC, the system HLD | `spec/` | C (`architect`) | Gate 2 |
| L4 LLDs, contracts, test plan | `lld/`, `contracts/`, `test/` | A | Gate 3 |
| L5 Milestone plans | `build/` | A (`planner`) | |
| L6 Handoffs | `build/` | A (`implementer`) | Code review |
| Audit state | `trace/` | A, derived | |
| Operations | `runbooks/`, `postmortems/` | A and C (`sre`) | |

## ID scheme

| ID | Example | Defined in |
| --- | --- | --- |
| Parent requirement | `FR-3`, `NFR-1`, `OUT-1`, `INV-1` | Parent PRD |
| Acceptance criterion | `IAM-2` | Component PRD; cited by tests and code with `@spec IAM-2` |
| Story, requirement, NFR, invariant, outcome | `IAM-US-1`, `IAM-FR-1`, `IAM-NFR-1`, `IAM-INV-1`, `IAM-OUT-1` | Component PRD |
| Decision | `ADR 0002` | `adr/` |
| Design section | `SPEC 4.2`, `LLD-iam §3` | SPEC and LLDs |

IDs are never renumbered and never reused.
