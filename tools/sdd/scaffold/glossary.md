# Glossary

Domain terms used across this project's documents, defined once. Terms used only inside one PRD can stay in that PRD's glossary section.

> **Owner:** A · **Persona:** `product-writer` (definitions), `doc-steward` (hygiene)

| Term | Definition |
| --- | --- |
| Acceptance criterion | A testable statement of behavior, written in EARS, with an ID such as `IAM-2`. |
| Gate | A human approval point: Gate 1 (PRD), Gate 2 (SPEC), Gate 3 (LLD). |
| Persona | A named role an agent plays when it writes or reviews part of a document. |
